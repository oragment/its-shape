# its shape

[English](./README.md) · **简体中文**

来自 **its** by **oragment** 的 Skill。

帮助零散想法沿与 its words 相同的外层路径逐渐成形：

**Flow → Structure → Work**

Structure 内部：

**Observation → Question → Idea**

Connect 与 Mainline 位于 Flow 与 Structure 之间。Later 暂存尚未进入当前主线的碎片。

## 适用场景

当你已经有碎片——笔记、想法、摘录、问题、未完成的工作——并想发现它们可能变成什么时使用。

## 安装

将本文件夹复制或克隆到支持的 skills 目录，例如在 Cursor 中：

- 项目级：`.cursor/skills/its-shape/`
- 个人级：`~/.cursor/skills/its-shape/`

然后让 agent 使用 **its shape**，或通过当前环境的 Skill 接口调用。

Skill 说明见 [`SKILL.md`](./SKILL.md)。

## 相关

其他 its Skills 可对应不同起点：

- **its empty** — 几乎还没什么可下手的材料
- **its chaos** — 碎片太多，看不清什么重要
- **its tight** — 卡在狭窄问题或固有假设里
