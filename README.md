# its shape

**English** · [简体中文](./README.zh-CN.md)

A Skill from **its** by **oragment**.

Helps fragmented thoughts gradually take shape along the same outer path as its words:

**Flow → Structure → Work**

Inside Structure:

**Observation → Question → Idea**

Connect and Mainline sit between Flow and Structure. Later holds fragments that are not part of the current Mainline.

## Use when

You already have fragments — notes, thoughts, quotes, questions, unfinished work — and want to discover what they might become.

## Install

Copy or clone this folder into a supported skills directory, for example in Cursor:

- Project: `.cursor/skills/its-shape/`
- Personal: `~/.cursor/skills/its-shape/`

Then ask the agent to use **its shape**, or invoke it through your environment's Skill interface.

The skill instructions live in [`SKILL.md`](./SKILL.md).

## Related

Other its Skills may cover different starting states:

- **its empty** — little or nothing to work with yet
- **its chaos** — too many fragments to see what matters
- **its tight** — stuck inside a narrow problem or assumption
